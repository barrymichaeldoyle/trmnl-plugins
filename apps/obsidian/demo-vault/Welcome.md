# Welcome

This is the demo vault for the TRMNL Screens plugin. Every note here feeds at least one screen:

- **Daily/** holds a week of daily notes. Today's note feeds the daily tasks screen, and the run of notes feeds the writing streak.
- **Projects/** carry due dates in both Tasks plugin and Dataview formats, so the due tasks screen has overdue, due today and upcoming tasks. Their frontmatter feeds the Dataview query screen.
- **Notes/** and **Books/** give the resurface screen something to bring back.
- **Focus.md** is the pinned note.

See the plugin's README in the repository for setup.
